# Dashboard

Interactive dashboard ที่รวมกราฟและแผนที่ของ Q1 และ Q2 ไว้ในหน้าเดียว แยกเป็น 2 แท็บ เลือกปี ตัวชี้วัด และขอบเขตได้ ชี้ที่เส้น จุด หรือจังหวัดเพื่อดูค่า

**เปิดดู:** https://sangsanfr.github.io/thailand-credit-access-gap/dashboard/ หรือดาวน์โหลด repo แล้วดับเบิลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งอะไรและไม่ต้องรันเซิร์ฟเวอร์ (ต่ออินเทอร์เน็ตเฉพาะตอนโหลดฟอนต์ ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน)

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | โครงหน้า สไตล์ และข้อความอธิบายแต่ละกราฟ |
| `theme.css` | สีและขนาดตัวอักษร (สลับโหมดสว่าง/มืดตามเครื่องอัตโนมัติ) |
| `runtime.js` | ตัวกลางที่ส่งข้อมูลให้โค้ดกราฟ (`dash.data`, `dash.calc`, `dash.onData`) |
| `common.js` | ค่าที่คำนวณจากข้อมูล, ตัวช่วยจัดรูปแบบตัวเลข, กราฟเส้น, การสลับแท็บ |
| `q1.js` | แท็บ Q1: Gini, LDR รายภาค, LDR เทียบสินเชื่อต่อหัว, β-convergence, ตารางรายจังหวัด |
| `q2.js` | แท็บ Q2: Moran's I, แผนที่ LISA รายจังหวัดและรายอำเภอ |
| `data/data.js` | ข้อมูลทั้งหมดของ dashboard สร้างด้วย `src/dash_data.py` (ขั้นที่ 5 ใน `run_all.sh`) |
| `lib/d3.v7.9.0.min.js` | ไลบรารี [D3](https://d3js.org) v7.9.0 (ISC license, ดู `lib/d3-LICENSE.txt`) |
| `preview_q1.png`, `preview_q2.png` | ภาพตัวอย่างสำหรับ README |

ข้อมูลเก็บเป็นไฟล์ `.js` แทน `.json` เพราะเบราว์เซอร์ไม่ยอมให้หน้าเว็บที่เปิดจากไฟล์ในเครื่องโหลด JSON ได้ ทำแบบนี้หน้าเดียวกันจึงใช้ได้ทั้งบน GitHub Pages และตอนดับเบิลคลิก
