# Dashboard

ซอร์สโค้ดของ interactive dashboard ที่รวมกราฟและแผนที่ของ Q1 และ Q2 ไว้ในหน้าเดียว แยกเป็น 2 แท็บ เลือกปี ตัวชี้วัด และขอบเขตได้ ชี้ที่จุดหรือจังหวัดเพื่อดูค่า

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | โครงหน้า สไตล์ และข้อความอธิบายแต่ละกราฟ |
| `common.js` | ค่าที่คำนวณจากข้อมูล (`dash.calc`), ตัวช่วยจัดรูปแบบตัวเลข, กราฟเส้น, การสลับแท็บ |
| `q1.js` | แท็บ Q1: Gini, LDR รายภาค, LDR เทียบสินเชื่อต่อหัว, β-convergence |
| `q2.js` | แท็บ Q2: Moran's I, แผนที่ LISA รายจังหวัดและรายอำเภอ |

ข้อมูลของ dashboard สร้างด้วย `src/dash_data.py` (ขั้นที่ 5 ใน `run_all.sh`) ได้เป็นไฟล์ JSON ใน `dashboard/data/`

**ข้อควรรู้:** โค้ดชุดนี้เขียนให้ทำงานบน dashboard runtime ของ Claude ซึ่งเป็นตัวจัดหา `dash` (โหลดข้อมูลและผูกตัวเลขกับ `data-source`), `d3` และตัวแปรสีของธีม จึงเปิด `index.html` ด้วยการดับเบิลคลิกตรง ๆ ไม่ได้ จะเห็นแค่ข้อความและเครื่องหมาย "—" ภาพนิ่งของกราฟทั้งหมดอยู่ใน `outputs/q1/fig/` และ `outputs/q2/fig/`
